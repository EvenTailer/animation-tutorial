# GRAMILYA — мастерская персонажа

Русский бесплатный маршрут для абсолютных новичков. Основной путь — 60 небольших шагов от первого овала головы до законченного исходного кибер-утёнка. На каждом шаге ровно одно действие и отдельная растровая панель. В подарок — 36 шагов существующего кибер-волка. После рисунка ученик изучает движение полного цветного героя: ожидание, бег, прыжок и удар. Рисование происходит в приложении на планшете.

## Запуск в Windows

Требуется Node.js. Из этой папки: `npm install`, затем `npm run dev`. Production: `npm run build`, просмотр готовой сборки: `npm run preview`.

Проверка программы и иллюстраций: `npm run check:content`. Форматирование кода: `npm run format`. Результаты браузерной проверки — в `docs/verification.md`.

## Структура

- `src/main.jsx` — точка входа, React Router и lazy-загрузка страниц через Suspense.
- `src/AppLayout.jsx` — общий каркас, NavLink, темы, индикатор сохранения и граница ошибок загрузки.
- `src/pages/` — отдельные страницы маршрута, мастер-класса, занятий, инструментов и шпаргалок.
- `src/store/` — Redux Toolkit: настройки и прогресс, миграция localStorage и резервные копии.
- `src/routing/paths.js` — проверяемые построители адресов шагов, занятий и кадров.
- `src/Masterclass.jsx` — основной мастер-класс, сохранение этапа, увеличение и сравнение с оригиналом.
- Навигация закреплена; выбор номера сохраняет положение страницы. На десктопе рисунок и текст имеют независимую прокрутку.
- `src/AnimationStudio.jsx`, `src/CharacterAnimation.jsx` — полноцветные позы, ручная прокрутка кадров, воспроизведение, калька и инструкции по движению.
- `src/data/masterclasses.js` — подробные этапы двух персонажей, слои, инструменты, палитры и проверки.
- `src/masterclass.css`, `src/drawing-path.css` — интерфейс мастер-классов и входы в учебный путь.
- `src/Diagram.jsx` — учебные SVG-схемы и последовательности поз.
- `src/data/curriculum.js` — программа, шаги, упражнения, критерии и типичные ошибки.
- `src/style.css` — адаптивная сетка и три цветовые темы.
- `public/assets/duck-hero.png` — предоставленный пользователем референс.
- `public/assets/cyber-boss.png` — дополнительный концепт, созданный ImageGen.
- `public/assets/duck-process-a.png`, `duck-process-b.png`, `boss-process.png` — растровые учебные листы.
- `public/assets/duck-hero-v2.png` — отдельный редизайн главного героя, не заменяющий исходный учебный референс.
- `public/assets/duck-hero-v3.png` — актуальный самостоятельный образ городского разведчика: индиговая куртка, бирюзовый шарф, компактный протез и лёгкие кроссовки. Старые концепты сохранены как архив.
- `docs/artwork.md` — происхождение иллюстраций и использованные направления промптов.

Прогресс и настройки хранятся в Redux Toolkit и сохраняются в едином ключе `gramilya-state-v1`. Старые ключи автоматически мигрируют при первом запуске. Сброс не восстанавливает старые отметки и сохраняет тему и программу. JSON-экспорт v4 включает настройки, прогресс, курсоры и архив; импорт v1/v2/v3 поддержан. Регистрации и загрузки рисунков нет.

Адреса: `/`, `/draw/duck/5`, `/draw/boss/2`, `/animation/run/8`, `/lesson/w1-l1`, `/tools`, `/library`. Шаги и кадры в адресах начинаются с 1. «Назад/Вперёд» возвращают выбранный шаг; автоматическое воспроизведение не создаёт запись истории на каждый кадр. `/draw` продолжает сохранённый шаг, `/lesson` — последнее занятие. Неизвестная страница показывает 404, некорректный шаг заменяется первым. SPA fallback для прямого открытия адресов задан в `.openai/hosting.json`.

`npm test` проверяет состояние, миграцию, резервные копии и построители маршрутов. Данные уроков и мастер-классов подключаются из страниц, а не из общего каркаса или store.

## Пределы учебного материала

10 недель — ориентир темпа, а не гарантия профессионального уровня. Растровые этапы созданы ИИ по референсам и показывают последовательность полноценного рисунка, но не являются исходными слоями или записью работы автора оригинала. Оригинал постоянно доступен рядом для проверки пропорций и деталей. Схемы вынесены в дополнительные упражнения и анимацию. Курс заканчивается подготовкой частей и экспортом; работу с программой рига ученик продолжает на ПК.

Приложения: Procreate (iPad), Clip Studio Paint (Galaxy), GoPaint (совместимые Huawei). Условия платных функций и поддержка анимации зависят от версии, модели и региона; официальные ссылки находятся на странице инструментов.
