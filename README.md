# Штрих — мастерская персонажа

Русский бесплатный маршрут для новичков. Основной путь — полная отрисовка исходного кибер-утёнка в 18 растровых этапах с 90 поддействиями. В подарок — 12 этапов существующего кибер-волка с 63 поддействиями. 10 недель и 30 упражнений помогают освоить основы, ракурсы, движение и экспорт. Рисование происходит в приложении на планшете.

## Запуск в Windows

Требуется Node.js. Из этой папки: `npm install`, затем `npm run dev`. Production: `npm run build`, просмотр готовой сборки: `npm run preview`.

Проверка программы и иллюстраций: `npm run check:content`. Форматирование кода: `npm run format`. Результаты браузерной проверки — в `docs/verification.md`.

## Структура

- `src/main.jsx` — React-интерфейс, навигация, настройки, прогресс и восстановление.
- `src/Masterclass.jsx` — основной мастер-класс, сохранение этапа, увеличение и сравнение с оригиналом.
- `src/data/masterclasses.js` — подробные этапы двух персонажей, слои, инструменты, палитры и проверки.
- `src/masterclass.css`, `src/drawing-path.css` — интерфейс мастер-классов и входы в учебный путь.
- `src/Diagram.jsx` — учебные SVG-схемы и последовательности поз.
- `src/data/curriculum.js` — программа, шаги, упражнения, критерии и типичные ошибки.
- `src/style.css` — адаптивная сетка и три цветовые темы.
- `public/assets/duck-hero.png` — предоставленный пользователем референс.
- `public/assets/cyber-boss.png` — дополнительный концепт, созданный ImageGen.
- `public/assets/duck-process-a.png`, `duck-process-b.png`, `boss-process.png` — растровые учебные листы.
- `public/assets/duck-hero-v2.png` — отдельный редизайн главного героя, не заменяющий исходный учебный референс.
- `docs/artwork.md` — происхождение иллюстраций и использованные направления промптов.

Прогресс упражнений и обоих мастер-классов, позиция внутри каждого персонажа, тема и программа сохраняются в localStorage этого браузера. Резервная копия JSON v2 включает оба вида прогресса; старые файлы v1 также импортируются. Регистрации, сервера с пользовательскими данными и загрузки рисунков нет.

## Пределы учебного материала

10 недель — ориентир темпа, а не гарантия профессионального уровня. Растровые этапы созданы ИИ по референсам и показывают последовательность полноценного рисунка, но не являются исходными слоями или записью работы автора оригинала. Оригинал постоянно доступен рядом для проверки пропорций и деталей. Схемы вынесены в дополнительные упражнения и анимацию. Курс заканчивается подготовкой частей и экспортом; работу с программой рига ученик продолжает на ПК.

Приложения: Procreate (iPad), Clip Studio Paint (Galaxy), GoPaint (совместимые Huawei). Условия платных функций и поддержка анимации зависят от версии, модели и региона; официальные ссылки находятся на странице инструментов.

## Дополнительный концепт

Создан встроенным ImageGen. Промпт: full-body hand-drawn cyberpunk anthropomorphic wolf boss, charcoal fur, cream mane, worn sleeveless shirt and dark cargo trousers, mechanical forearm, cyan/magenta accents; gritty ink outlines, flat shading, plain warm-grey background, no text. Это пример для самостоятельной практики.
