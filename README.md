# GRAMILYA — мастерская персонажа

Рисуем исходные арты нового утёнка и льва Гордыни в их оригинальных позах. Затем отдельный раздел переводит героя в игровой профиль и учит рисовать движение. Пользователь рисует в приложении на планшете; сайт показывает построения, объясняет действия и сохраняет отметки.

- Герой: 84 действия, 7 глав по 12 панелей; исходная динамическая поза в три четверти.
- Лев: 96 действий, 8 глав по 12 панелей; исходные шпага влево, хвост вправо, вторая рука за спиной.
- Оба рисунка начинаются на горизонтальном холсте 3600 × 2400, с композиции именно пользовательского арта.
- Движение: ожидание 4 позы, бег 6, прыжок 6. У каждой позы 12 учебных шагов — всего 192. Атака отложена.
- Построения: земля, ось, четыре цепочки конечностей, объёмы, силуэт, костюм, базовый цвет, свет и проверка. Просмотр итогового движения включается отдельно.
- Эталон движения собран из растровых частей с постоянными анатомическими ID. Правая рука и левая голень механические; зеркального отражения нет. Это cutout-эталон для обучения построению, а не готовая рисованная игровая анимация.
- Procreate/iPad, Clip Studio Paint/Galaxy и GoPaint/MatePad имеют отдельные кисти, пути меню, настройки и упражнения. Ограничения версии, модели и пера указаны рядом с официальными источниками.
- Revision 5 отделяет новые курсы и 12-шаговые отметки от старых профильных уроков. Старые отметки архивируются, резервные копии сохраняют новый прогресс.

## Запуск в Windows

Из этой папки: `npm install`, затем `npm run dev`. Готовая сборка: `npm run build`, затем `npm run preview -- --port 4173`. Адрес: http://127.0.0.1:4173/.

## Проверки

- `npm test` — маршруты, Redux, миграция, резервные копии, учебные этапы и соединение конечностей.
- `npm run check:content` — 180 действий рисунка и их иллюстрации.
- `npm run check:animation` — 16 поз, 192 учебных шага, постоянные стороны тела, границы, опора и полёт.
- `npm run build` — production-сборка.

## Основные файлы

- `src/data/duckMasterclass.js`, `lionMasterclass.js` — курсы по исходным артам.
- `src/data/animationDrawing.js` — действия, проверки и ошибки каждого шага каждой позы.
- `src/data/animationParts.js`, `animationRig.js` — части, суставы и опора.
- `src/animationRaster.js` — построения, эталон, калька и экспорт PNG одним рендерером.
- `src/DeviceDrawingGuide.jsx`, `src/data/apps.js` — настройки и практика для каждой программы.
- `public/assets/*-original-*-steps-v5.png` — 15 учебных листов по исходным артам.
- `docs/duck-original-v5-artwork.md`, `lion-original-v5-artwork.md`, `animation-v5-artwork.md` — происхождение и проверка изображений.
- `docs/original-v5-qa/` — снимки актуальной версии.

Адреса: `/draw/duck/1`, `/draw/boss/1`, `/animation/run/1`, `/tools`. Растровые иллюстрации созданы ИИ по пользовательским референсам и служат учебными ориентирами; оригиналы доступны для сравнения. Между ключевыми позами ученик дорисовывает промежуточные фазы.

Документы и снимки `profile-v4-*` относятся к предыдущей профильной версии. `animation-qa-2026-10-30.md` и `animation-qa/` относятся к отклонённому фронтальному прототипу. Они сохранены как история, а не как проверка текущей версии.
