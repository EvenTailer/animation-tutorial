# Проверка движения нового героя — 30 октября 2026

Обновлены ожидание (4 фазы), бег (8) и прыжок (6). Используется точная копия пользовательского модельного листа duck-current-model.png, без зеркального отражения. Правая рука и левая голень героя механические. Атака отложена; прежние листы рисунка обозначены архивом. Референс босса заменён на пользовательского льва Гордыню, его анимация в эту итерацию не входит.

## Работа команды

Дизайнер зафиксировал особенности новой модели. Архитектор обновил референсы и учебный маршрут. Основной критик проверил опору, описание фаз и управление. По замечанию владельца добавлен отдельный критик качества анимации.

Первые варианты были отклонены: генерация меняла стороны протезов, независимые вырезанные части оставляли дыры у таза, первоначальные веса сетки смешивали колено с рукой. Финальный вариант использует цельную текстуру, отдельные области влияния рук, фронтальную проекцию ног и ограничения площади/длины рёбер. Критик визуально просмотрел все 8 фаз бега и 6 фаз прыжка; принял их как учебный фронтальный риг без блокирующих разрывов и перепутанных конечностей.

## Проверки

- npm test: 25 проверок проходят, включая опору стоп, порядок суставов и исключение колена/поясной ткани из весов рук.
- npm run check:content: актуальный модельный лист, согласованные числа фаз и уроков; архивные материалы существуют.
- npm run check:animation: 18 поз, 7891 непрозрачный треугольник и 11131 непрозрачное ребро. Перевёрнутых треугольников нет. Максимальное растяжение ребра 1.8 при пороге аудита 2.25.
- npm run build: проходит.
- В браузере проверены все фазы, воспроизведение, пауза и калька. Ошибок JavaScript при проверке не обнаружено. Снимки: animation-qa/run-01.jpg…run-08.jpg, jump-01.jpg…jump-06.jpg, idle-01.jpg…idle-04.jpg.

## Границы результата

Это фронтальная учебная демонстрация по готовому арту, а не финальные игровые sprite sheets. Для игрового бокового бега нужны отдельные ракурсы и промежуточные рисунки. Экспорт сейчас скачивает исходный лист модели и прямо обозначен как референс. Новые пошаговые листы рисования героя и льва не создавались.

Для локального просмотра собранной версии: npm run preview -- --port 4173. Dev-сервер в текущей ограниченной Windows-среде столкнулся с отказом чтения каталогов при prebundle; production preview использован для визуальной проверки.
