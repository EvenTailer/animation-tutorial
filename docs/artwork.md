## Учебные листы

Встроенный ImageGen создал новые растровые изображения по исходникам. Это поэтапные учебные иллюстрации, а не извлечённые слои оригинальной работы художника и не видеозапись её создания. В интерфейсе оригинал всегда доступен для сверки. CSS показывает одну ячейку листа; файл не режется и не изменяется браузером.

Промпты задавали одинаковую позу и пропорции во всех ячейках, равномерную сетку, светлый бумажный фон без текста и нумерации:

- `duck-process-a.png`: сетка 3×3. Манекен → анатомические объёмы → голова и клюв → глаза и имплант → хохолок/перья → механическая шея → майка → органические руки и перчатка → протез предплечья и кисти. Только фронтальная исходная утка; оригинальная одежда. Отдельная правка закрепляет протез слева на изображении, органическую руку справа и визуальное появление перьев между этапами 4 и 5.
- `duck-process-b.png`: сетка 3×3. Брюки и складки → пояс и уточнение жетона → карманы и снаряжение → кроссовки → очищенный контур → плоские цвета → большие тени → фактуры → финальные акценты. Поза, импланты и одежда соответствуют исходному фронту.
- `boss-process.png`: сетка 4×3. Манекен → объёмы → голова → закрытая пасть/нос/глаза/шрамы → грива → рваная майка и ремни → органическая и механическая руки → брюки/хвост/кроссовки → контур → цвет → свет → финальные текстуры. Сохранены исходные органическая рука слева и светлый протез справа на изображении.
