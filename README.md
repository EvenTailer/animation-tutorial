# GRAMILYA — мастерская персонажа

Текущая версия: новые утёнок и лев Гордыня в боковом ракурсе для метроидвании. Рисование происходит в приложении на планшете; сайт показывает этапы, воспроизводит примеры и сохраняет отметки.

- Новый утёнок: 60 действий и 5 растровых листов по 12 панелей.
- Лев Гордыня: 36 действий и 3 растровых листа по 12 панелей.
- Передвижение героя вправо: ожидание — 4 позы, бег — 6, прыжок — 6. Атака отложена.
- Просмотр, калька и экспорт PNG используют одну функцию отрисовки. Экспорт содержит те же выровненные кадры на холсте 512 × 600.
- Правая рука и левая голень героя механические. Асимметричный арт не отражается.
- Старые отметки рисунка и анимации мигрируют в архив; профильные уроки имеют собственные ID и revision 4.

## Запуск в Windows

Из этой папки: npm install, затем npm run dev. Готовая сборка: npm run build, затем npm run preview -- --port 4173. Адрес: http://127.0.0.1:4173/.

## Проверки

npm test — маршруты, Redux, миграция и резервные копии. npm run check:content — 96 новых этапов и их иллюстрации. npm run check:animation — прозрачность, полные границы поз, общий масштаб, опора и полёт. npm run build — production-сборка.

## Основные файлы

- src/data/duckMasterclass.js и lionMasterclass.js — новые уроки; masterclasses.js объединяет их.
- src/data/animation.js — фазы, длительности и инструкции.
- src/data/animationSheets.js — исходные прямоугольники и якоря поз.
- src/animationRaster.js — общая отрисовка и экспорт; CharacterAnimation.jsx и AnimationStudio.jsx — просмотр.
- public/assets/duck-profile-*-steps-v4.png и boss-lion-profile-*-steps-v4.png — новые учебные панели.
- public/assets/duck-profile-{run,jump,idle}-v4.png — исходные листы боковых поз.
- docs/duck-profile-v4-artwork.md и docs/lion-profile-v4-artwork.md — источники, промпты и визуальная проверка.
- docs/profile-v4-qa/ — снимки актуальных страниц и PNG бега, скачанный из приложения.

Адреса: /draw/duck/1, /draw/boss/1, /animation/run/1. Растровые панели и позы созданы ИИ по пользовательским референсам; это учебные ключевые рисунки. Для плавной игровой анимации нужны промежуточные позы.

Отчёт docs/animation-qa-2026-10-30.md и снимки docs/animation-qa/ относятся к отклонённому фронтальному прототипу и сохранены как история, не как проверка текущей версии.
